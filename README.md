# Smart Expense Tracker

## Project Description

Smart Expense Tracker is a web-based application used to record, manage, search and track daily expenses.

## Technologies Used

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Git & GitHub

## Features

- Add Expense
- View Expenses
- Update Expense
- Delete Expense
- Search Expenses
- Filter by Category
- Calculate Total Expense

## Expense Categories

- Food
- Travel
- Shopping
- Education
- Other

## Project Architecture

User → HTML/CSS/JavaScript → Spring Boot REST API → Spring Data JPA → MySQL

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/expenses` | Add expense |
| GET | `/api/expenses` | View all expenses |
| GET | `/api/expenses/{id}` | View one expense |
| PUT | `/api/expenses/{id}` | Update expense |
| DELETE | `/api/expenses/{id}` | Delete expense |

## Database

Database Name: `expense_tracker`
